# Forward Gravity Modelling

A Python-based graphical user interface (GUI) application developed to demonstrate the basic concept of forward gravity modelling. The program computes a synthetic gravity anomaly based on user-defined density contrast and depth parameters while visualizing a simplified two-dimensional subsurface model.

## Features

- Interactive graphical user interface (GUI)
- Synthetic gravity anomaly calculation
- 2D subsurface model visualization
- Adjustable density contrast (g/cm³)
- Adjustable model depth (m)
- Real-time graphical plotting using Matplotlib

## Libraries

- Python 3.13
- Tkinter (GUI Framework)
- NumPy (Numerical Computation)
- Matplotlib (Data Visualization)

## Output

The application generates two graphical outputs:

- **Gravity Response** – Displays the synthetic gravity anomaly along the observation profile.
- **2D Model** – Displays a simplified rectangular subsurface body at the specified depth.
